Homelab — 2 servers

自宅サーバー運用

自宅で2台のサーバーを運用しています。メインサーバーでは写真・動画を保管する immich を、Raspberry Pi 4 では OpenMediaVault の NAS を動かしています。

Server 01 メインサーバー
Hardware
FIREBAT T2 ミニPC（Intel N150 / 16GB / SSD 512GB）
OS
Ubuntu 24.04
Service
immich（Docker）, Tailscale
Googleフォトの容量が100GBを超えたのをきっかけに、写真と動画を自分のサーバーで保管するようにしました。CPU は省電力のものを選びました。写真と動画は、ブラウザやアプリから見返しています。 構築記事：【脱Googleフォト】Immichを構築してみた ↗
Server 02 Raspberry Pi 4（NAS）
Hardware
Raspberry Pi 4 ＋ 2TB HDD
OS
Raspberry Pi OS
Service
OpenMediaVault
OpenMediaVault で NAS として使っています。HDD は、以前 PC を自作していたときのものを流用しています。

02 — 動かしているもの

  • immich メインサーバーで、公式のクイックスタートに沿って Docker Compose で動かしています。Googleフォトの代わりに、写真と動画をここに保管しています。構築記事 ↗
  • OpenMediaVault Raspberry Pi OS にインストールし、2TB の HDD をつないで NAS として使っています。
  • Time Machine Mac のバックアップ先として使っています。
  • Tailscale 外出先から自宅のサーバーにつなぐために使っています。

03 — 運用で気をつけていること

immich の写真・動画は、定期的に NAS へバックアップしています。
OS（Ubuntu）と immich の更新は、Claude のスケジューラーに任せています。

04 — 今後

3-2-1 ルールでの immich のデータのバックアップ、Google アカウントでのログイン（OAuth）、リバースプロキシでの公開を予定しています。
