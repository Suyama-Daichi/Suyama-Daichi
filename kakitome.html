kakitome

書き留めて、チェックして、忘れない。チェックリストとホーム画面のウィジェットを中心にしたメモアプリ。

Google Play ↗ LPを開く ↗ GitHub ↗
Role
企画・設計・開発
Status
開発中
Android・Webは暫定公開
Stack
Expo, TypeScript, SQLite, Google Drive API
Platform
iOS / Android / Web

01 — 背景

Google Keepの代替として自分用に作っています。

02 — 主な機能

  • チェックリスト チェックリストを作り、終わった項目からチェックを付けられます。
  • ホーム画面ウィジェット AndroidとiOSのホーム画面のウィジェットから、アプリを開かずにチェックを付け外しできます。iOSでは、次にアプリを開いたときにメモへ反映されます。
  • iOS / Android 同期 iPhoneとAndroidのどちらでも同じメモを使えます。
  • リマインド 決めた時間に通知して、やり忘れを防ぎます。
  • Googleアカウントで開始 新しいアカウントを作らずに、Googleアカウントですぐに始められます。
  • 画像の添付 メモに写真を添付できます。保存するときに縮小してJPEGにし、位置情報などのEXIFは取り除きます。
  • Google Keepから取り込み Web版では、Google Takeoutで書き出したGoogle Keepのメモを画像ごと取り込めます。同じファイルをもう一度選んでも、メモは重複しません。

03 — 設計のポイント

運用コストを抑える 同期の方式は、コストを抑えられることを最優先に選んでいます。
自前サーバーを持たない サーバーを運用せず、ユーザーのデータも預からない構成を目指しています。
1つのコードで2つのOS Expoを使い、iOSとAndroidを同じコードベースで開発しています。

04 — 技術構成

Expo（Development Build）と Expo Router、TypeScript で、iOS・Android・Web を1つのコードベースから作っています。
データは端末の SQLite（expo-sqlite）を正とするローカルファースト構成です。変更はすべて操作ログとして記録し、ユーザー自身の Google Drive（appDataFolder）にだけ送ります。自前のサーバーや BaaS は使っていません。
同時に編集したときは、HLC（ハイブリッド論理時計）で比べてフィールドごとに後勝ちで解決し、並び順は分数インデックスで持っています。
ウィジェットは Android が react-native-android-widget、iOS が expo-widgets、リマインドは expo-notifications のローカル通知です。Web 版は GitHub Actions で型チェック・oxlint・Jest を通したあと、Cloudflare Pages に自動で公開しています。
