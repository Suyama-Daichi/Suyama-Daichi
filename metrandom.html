Web App — Personal

metrandom.com

ボタンひとつで、地下鉄の駅をランダムに1つ選ぶWebアプリ「メトロ駅ガチャ」。途中下車する駅や休日のお散歩先に迷ったときに。

企画・デザイン・開発
Year
2026
Stack
HTML / CSS / Vanilla JS, Cloudflare Pages, OpenPOI API
Language
日本語・英語・中国語（簡体字）

01 — 背景

週末にお出かけする目的地を、楽しく決められるものが欲しくて作りました。
目的地はAIに聞いても選んでもらえますが、PWAにして、スマホからサクッと回せるようにしています。

02 — 主な機能

  • 駅ガチャ ボタンを押すとルーレットのように路線と駅が回り、1駅が決まります。東京は東京メトロ9路線と都営地下鉄4路線、あわせて291駅から選びます。
  • 東京・大阪・名古屋大阪メトロ版と名古屋市営地下鉄版もあります。
  • 路線の絞り込み対象の路線は、事業者ごとにも路線ごとにも絞り込めます。
  • 周辺スポットの提案 出た駅の周りにある、チェーン店以外の飲食店・公園・観光スポットを、OpenPOI API のデータから紹介します。駅の場所はGoogleマップでも確認できます。
  • 履歴と共有 直近の結果を履歴に残し、タップで見返せます。駅ごとに共有用のページとOGP画像を用意しています。
  • 3言語対応日本語・英語・中国語（簡体字）に対応。
    ブラウザの言語に合わせて自動で切り替わり、手動でも変更できます。

03 — 技術構成

HTML・CSS・Vanilla JavaScript だけで作った静的サイトで、フレームワークやビルドツールは使っていません。
路線・駅のデータは都市ごとの JS ファイルに持っています。駅ごとの共有ページ（東京は291駅×3言語）と大阪・名古屋版のトップは Node.js のスクリプトで生成し、大阪・名古屋の OGP 画像はヘッドレス Chrome で作っています。
ホスティングは Cloudflare Pages で、GitHub の main ブランチに push すると自動でデプロイされます。SEO 向けに OGP・Twitter カード・JSON-LD・sitemap.xml を用意しています。

04 — 集客と今後

SEOによる集客を検証しています。広告収入は、今後のアクセス数を見て検討します。
