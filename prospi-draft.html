プロスピ2026 ランダムドラフト

『プロ野球スピリッツ2026』の収録選手から、ルーレットで候補を出して1人ずつ指名し、17人のマイチームを作るツール。

サイトを開く ↗ GitHub ↗
Role
企画・デザイン・開発
Year
2026
Stack
HTML / CSS / Vanilla JS, Python, Cloudflare Workers, GitHub Actions
Language
日本語

01 — 主な機能

  • ルーレットで指名 ルーレット1回で候補を1〜20人（初期値7人）出し、そのうち1人を指名します。パスは3回までです。
  • 17人の起用枠 打順1〜9番、控え2、先発3、中継ぎ2、抑えの17枠。どの選手もどの枠にも入れられます。スタメン9人の守備は重複できません。
  • 区分の絞り込み ルーレットに出す区分（12球団・WBC2026代表・歴代日本代表・OB・WORLD STAR）を絞り込めます。
  • 編成の共有 作った編成は画像とテキストで共有できます。

02 — 技術構成

ページは HTML・CSS・Vanilla JavaScript で作り、Python のスクリプトで選手データ（CSV）を埋め込んで1つの HTML を生成しています。
ホスティングは Cloudflare Workers の静的アセット配信で、GitHub と連携して自動でデプロイされます。
収録選手は GitHub Actions が毎週確認し、ゲームのアップデートがあれば NPB の名簿データと Wikipedia をもとに更新案の PR を作ります。
